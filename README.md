# Pikachu Forest Adventure

A small browser-based 2D free-roaming forest game. Move Pikachu with WASD or arrow keys and hold Shift to run.

## Run
Open `index.html` in a modern browser. No build step or dependencies are required.

The game uses original canvas-drawn art for Pikachu, trees, terrain, flowers, rocks, pond, camera and UI rather than bundled Pokémon asset files.
